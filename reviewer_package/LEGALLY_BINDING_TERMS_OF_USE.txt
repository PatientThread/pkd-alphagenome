MODIFICATIONS MADE TO OUTPUT
--------------------------------------------------------------------------------

The Terms require notice of modifications. The predictions redistributed here
are not raw API responses in every case. They were transformed as follows, and
the code that did so is in analysis/ :

  - Atlas AVI scores and attributions are stored as returned, one row per
    variant (analysis/06).
  - On-demand scores (analysis/07) were reduced, for each variant, to the row of
    the variant's own gene (PKD1 or PKD2) and summarised as the maximum absolute
    value across all tracks and across a curated set of kidney tracks, with the
    signed value and track name at that maximum.
  - Locus percentiles were computed by ranking each truth-set AVI score against
    all Atlas AVI scores in the same locus; AVI feature attributions were summed
    into four groups (splicing, expression and chromatin, protein, conservation)
    (analysis/12).
  - No model weights or parameters are redistributed, and none were accessed.
